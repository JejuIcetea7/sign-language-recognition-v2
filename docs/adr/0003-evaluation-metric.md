# 0003 수어 분류 모델 평가 지표 선정  

## Status  
Proposed  


## Context  
여러 모델의 성능을 동일한 기준으로 평가하고, 최종 모델을 선택하기 위하여 대표 평가지표를 선정한다.  


## Decision  

대표 평가 지표로 Macro-F1을 사용하고, 보조 지표로 Accuracy를 사용한다.  


**결정 이유**
- 22개 클래스에 대해서 클래스당 영상은 48-60개 이며 대체로 균형이다. 
- 클래스가 대체로 균형이기 때문에 Acc와 Macro-F1에서 대체로 차이가 없지만 클래스별 f1을 확인하여 squid, chicken 클래스의 성능 저하를 확인할 수 있다.  




## Consequences  
- 특정 클래스의 성능 저하를 확인할 수 있다.  
- 모델 튜닝과 최종 선정은 Macro-F1을 이용한다.
