# 0004 평가에서 같은 사람의 영상이 학습과 시험에 섞이는 문제

## Status  
Proposed  


## Context  
- 데이터는 4명이 22개 단어를 각각 12~15번씩 촬영한 영상 1272개이다.
- 지금 평가는 영상 단위 stratified 5-fold이다. 같은 영상이 학습과 시험에 나뉘어 들어가지는 않지만, 같은 사람의 다른 영상은 섞인다.
- 확인한 결과 (6프레임, GRU, 사람 1명씩 제외하고 학습):

| 평가 방식 | Accuracy | Macro-F1 |
|---|---|---|
| 무작위 5-fold (seed 42) | 83.25% | - |
| 사람 단위 (4명 평균) | 78.77% | 79.02% |

- 사람별 Accuracy: person1 78.3%, person2 76.1%, person3 78.0%, person4 82.7%
- 그 외 누수 점검: 학습/시험 영상 겹침 0, 완전히 같은 샘플 0.


## Decision  
당분간 무작위 5-fold를 유지하고, 사람 단위 평가는 하지 않는다.  
성능을 보고할 때 "같은 사람이 섞인 평가"임을 함께 적는다.


## Consequences  
- 보고하는 성능은 처음 보는 사람에 대한 성능보다 약 4.5%p 높게 나온다. (사람 4명 기준의 대략적인 값)
- 같은 분할 안에서 모델이나 시퀀스 길이를 비교하는 실험은 이 문제와 별개로 진행한다.
- 사람 단위 평가는 이후 과제로 남긴다.
